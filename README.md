# CareerPlus Academy

CareerPlus Academy is your partner in professional exam preparation. This website aims to provide job advertisements, syllabuses for competitive exams (like CSS, PMS, PPSC), and practice materials for general job papers. It also offers practice facilities for skills like typing and shorthand.

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** ShadCN UI
